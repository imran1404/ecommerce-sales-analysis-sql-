# Power BI Dashboard

This folder contains the Power BI report developed for the E-Commerce Sales Analysis project.

The dashboard transforms the SQL-analyzed data into interactive visual reports that help understand sales performance, customer behavior, product performance, and order trends.

## Dashboard Features

- KPI Cards
- Revenue Analysis
- Product Performance
- Customer Analysis
- Order Analysis
- Interactive Slicers
- Data Visualization
- DAX Measures
- Interactive Filtering

## File

The main Power BI report is provided in this folder as a `.pbix` file.
