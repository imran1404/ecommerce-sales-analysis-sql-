# SQL Queries

This folder contains the SQL queries used to analyze the E-Commerce database.

The queries progress from basic SQL analysis to more advanced analytical techniques and are organized according to the type of analysis performed.

## Query Categories

### Basic Queries
Basic data retrieval and filtering using:

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions

### JOIN Queries
Queries combining multiple tables using:

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Multi-table JOINs

### Advanced Queries
More advanced analytical techniques including:

- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Ranking
- Running totals
- Comparative analysis

### Business Analysis

Queries designed to answer real-world e-commerce business questions such as:

- Which products generate the highest revenue?
- Which categories perform best?
- Who are the top customers?
- How does revenue change over time?
- Which payment methods are most frequently used?

## Purpose

The goal of these queries is not only to demonstrate SQL syntax, but also to use SQL to answer meaningful business questions and generate actionable insights.
